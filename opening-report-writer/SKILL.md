# 开题报告写作与格式

默认中文。学习参考的论证结构与版式，不复制人物、研究数据、方法结果或学校身份。参考材料由用户提供，不依赖固定本机目录；没有范文仍可开展题目分析和写作。精确模板复刻需取得原文件，不假称查看过。本 Skill 不附带开题报告、学校模板、论文全文或用户项目材料。

## 按任务读取

- 拆题、写提纲或研究方案：读 [题目到方案](references/topic-to-plan.md) 和 [章节写法](references/section-writing-guide.md)。
- 学习、规划、撰写或诊断开题报告研究现状：读 [章节写法](references/section-writing-guide.md) 的1.2；需要示范句子取舍、论证修复或比较时，再读 [研究现状写法案例](references/research-status-cases.md)。公开包案例为虚构教学材料，不是文献证据；需要真实论文写法分析时，读取用户提供或可合法获取的原文并给实际定位。
- 学习范文格式、按范文排版或生成 Word：读 [格式指南](references/format-rules.md)，先按其中的“从参考材料学习”区分实际观察、共性和建议；同时学习章节与段落写法时再读章节指南。
- 全文：读取题目到方案、章节写法和格式与来源对照；写法案例按需读取。只修改一节时只读相关小节，不重做全部调研。
- 本 Skill 专注开题报告写法与格式，不要求安装其他学术写作 Skill，也不修改或覆盖它们。

## 任务范围

识别是写法学习、选题分析、提纲、正文、审阅还是仅排版。问答和审阅只读；只有要求生成或修改时才写文件。“先学习并总结”停在有来源的理解总结，不自动进入正文修改；已授权写作则不以学习总结代替交付。只提供题目则输出暂定提纲和缺失输入；资料充分且已授权全文时，内部先定结构再完成正文，不逐章等待批准。用户明确要求先确认提纲时才停在该点。

先从上下文识别专业、学位、题目、对象/任务、已有材料、数据与标签、方法想法、已有成果、模板和期限。不默认学位层次，不从范文推断身份。不重复问已知信息。缺失但不阻塞的内容标注待补后继续；对实质改变课题的缺失选择集中询问一次，不能擅自替用户决定。

## 事实与计划

- 区分“用户材料中的事实”“待外部核验主张”“推断”“拟开展方案”“缺失信息”。用户提供的结果可标为其初步结果，不升级为独立复现。
- 范文是写法证据，不是科学正确性的证据。不能把范文数据、模型效果、课题来源、获奖发表或导师意见写成用户的。
- 拟创新必须对应文献不足、具体差异和可验证设计；未经查新不称首次，未实验不称已提升。不要以模块名组合替代研究问题。
- 保留已有数据划分、种子、标签层级、实验协议和结论限定。医学/WSI 任务区分患者、切片、patch，不把切片标签当实例真值，不把算法指标写成临床获益；非医学题目不强加医学流程。
- 学术事实与参考文献在需要时查原始来源。不能获取来源时给待补材料清单，草稿可用“[待补：支持某主张的文献]”，不得造作者、年份、DOI 或看似真实的数字引用。

## 执行顺序

1. **拆题**：对象—任务—约束—候选方法—验证目标。识别过宽题目，给收敛建议而不擅自改题。
2. **定主线**：现实问题 → 已知方法及不足 → 研究问题 → 目标 → 工作项 → 方法/技术路线 → 对照与评价 → 预期交付。
3. **建映射**：每个工作项在研究内容、难点、方案、预期目标中用同一名称/编号对应；需要多少项由课题决定，不凑三项或四项。
4. **组织章节**：无指定结构时采用下列五部分骨架。当前用户明确要求和指定模板优先；冲突说明，不混搭。默认不新增独立目录、创新点或可行性一级章。
5. **起草**：背景落到问题；综述围绕研究问题组织已有进展与方法比较，按证据收束到研究问题，不强行为每篇文献制造不足；方案解释机制和验证。拟开展与已完成分开。中文完整段落，不把提纲直接扩成重复列表。
6. **排版**：只在需要 Word 时读取格式参考；环境提供 documents 工作流时优先使用，否则使用可用的 DOCX 编辑和渲染工具。保留可编辑内容，生成后渲染并逐页查看。缺少生成或渲染工具时说明未完成项，不将文本交付冒充 Word，不宣称已完成视觉检查。已有模板视觉高于通用文档美化规则。
7. **相关检查**：题目与主线一致、工作项覆盖、引用对应、时间可行、数值口径一致；Word 另查样式、编号、图表和最终渲染。只修复当前发现的问题，不无限检查。

## 默认正文骨架

```text
报告正文
1.论文选题依据
  1.1论文选题的意义
  1.2国内外研究现状
    1.2.1概述
    1.2.2研究现状
    1.2.3发展趋势
2.论文研究方案
  2.1研究目标及研究内容
    2.1.1数据集和评价指标
    2.1.2主要研究内容
  2.2拟解决的关键问题及难点
  2.3拟采用的研究方案
3.预期达到的目标
4.论文工作计划
5.主要参考文献
```

非数据驱动题目可在模板允许下把 2.1.1 改为研究材料/对象与评价方法。创新点通常在 2.1.2 和 2.3 明确、在第3部分概括；可行性与已有基础可写入 2.3，不自动加章。封面、专家审核、选题信息、答辩记录和评议表仅按用户要求或实际模板加入，细节见格式参考。签名、成绩、审批意见不得生成；未知身份留空。

## 输出约定

按请求给产物，不强制每次输出全套表格：

- 选题/提纲：拆题、章节及逐节要写什么、工作项—方法—评价对应、关键待补材料。
- 研究现状学习/规划：学习时区分原文组织与归纳建议，给来源位置和迁移边界；规划时给分类依据、段落中心问题、比较维度、证据需求和衔接。具体流程见章节指南，不额外启动另一套完整写作流程。
- 正文：所需章节及引用，另附简短待核实清单；不把工作说明混入正式正文。缺关键事实的全文称草稿。
- 审阅：具体问题优先，定位原句，区分事实错误、证据不足、结构问题与表达偏好；说明保留、补充、压缩、移位或删除的理由，不直接改文件。
- Word：交付 DOCX、采用的格式依据及真实验证范围。保存成功不等于版式通过；渲染失败明确披露，不能称已视觉验证。

区分用户当前模板要求、参考材料中的观察、建议默认和未确定项。格式已在当前参考中明确的不要反复追问；学校当前正式要求、引用标准版本和篇幅等无法推断的才标记未确定。
