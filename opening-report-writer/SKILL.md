# 开题报告写作与格式

默认中文。学习参考的论证结构与版式，不复制人物、研究数据、方法结果或学校身份。参考材料由用户提供，不依赖固定本机目录；没有范文仍可开展题目分析和写作。精确模板复刻需取得原文件，不假称查看过。本 Skill 不附带开题报告、学校模板、论文全文或用户项目材料。

## 先确定本次交付

从当前请求与已有材料识别题目、对象/任务、模板、证据、修改范围及产物。复用已知的专业、学位、数据、方法、成果和期限，不从范文推断身份，也不要求填完整问卷。非阻塞缺口标注后继续；只有会实质影响课题或交付的缺失选择才集中询问。

只有题目且未指定产物时默认规划；明确要求草稿时完成可成立的授权章节，候选设计保持拟定状态，依赖未给事实的部分待补。只学习、诊断或规划时不改报告；在对话中起草不自动授权写文件。已授权全文且资料充分时完成全文，不逐章等待批准；明确要求先确认提纲时才停在该点。

完整报告未给篇幅时，按正文约10,000字作软预算，不因默认预算删减指定内容或凑字数；明确要求优先，局部任务不套全文字数。具体适用范围及询问时机见[题目到方案](references/topic-to-plan.md)第6节。

## 按任务读取与交付

| 本次任务 | 读取范围 | 应交付的内容 |
| --- | --- | --- |
| 拆题、提纲、方案规划 | [题目到方案](references/topic-to-plan.md)；[章节写法](references/section-writing-guide.md)对应章节 | 具体对象与约束、逐节要点、工作项—方法—验证对应；按影响列下一步最少材料及用途，通常不超过三项 |
| 学习范文或论文写法 | 章节写法1.2；涉及版式时读[格式指南](references/format-rules.md)“从参考材料学习” | 原文位置、组织动作、共性/差异和迁移边界，区分观察与建议；不自动改正文 |
| 研究现状规划 | 章节写法1.2 | 分类主轴、段落中心问题、共同维度、所需证据与衔接 |
| 起草或修改正文 | 章节写法对应小节；首次组织全文再读题目到方案 | 授权范围内的连续正文与引用；过程说明、待移内容及关键待核项放正文外 |
| 诊断草稿 | 章节写法对应小节 | 定位原句，区分事实错误、证据不足、结构问题与表达偏好；说明保留/补充/压缩/移位/删除，不改文件 |
| Word生成或仅排版 | 格式指南；需改内容时再读对应章节 | 可用工具支持的DOCX、格式依据和真实检查范围；仅排版不改研究内容 |

根据导师意见或用户反馈返修时，还读章节写法“根据反馈继续修改”；涉及新增、替换或移动引用时，还读第5节，它适用于任何章节。需要句子取舍示范时才读[研究现状写法案例](references/research-status-cases.md)，其中虚构材料不能作学术证据。真实论文学习需读实际原文并给位置。只处理一节不重做全文调研，也不强制读取全部参考文件。

## 组织与成稿

规划或写作时先明确“现实问题 → 已有进展及边界 → 研究问题 → 工作项 → 方法与验证 → 预期交付”。工作项在相关章节中用同一名称对应，数量由课题决定；题目过宽给收敛建议，不擅自换题。

学校当前正式要求与用户明确要求优先。没有指定结构时用题目到方案中的默认五部分骨架；参考指南编号仅表示默认职责，不能覆盖实际模板，不自动新增独立目录、创新点或可行性一级章。

先依据材料形成判断，再按章节职责写连贯段落：背景落到问题，综述解释进展与路线关系，方案解释机制和验证。不要把提纲扩成重复列表，不为每篇文献制造缺点。局部修改保留成立内容；需移出细节但未授权目标章节时，在正文外完整保留待移文本与建议位置，不直接改其他章节。

## 事实与计划

- 区分“用户材料中的事实”“待外部核验主张”“推断”“拟开展方案”“缺失信息”。用户提供的结果可标为其初步结果，不升级为独立复现。
- 范文是写法证据，不是科学正确性的证据。不能把范文数据、模型效果、课题来源、获奖发表或导师意见写成用户的。
- 拟创新必须对应文献不足、具体差异和可验证设计；未经查新不称首次，未实验不称已提升。不要以模块名组合替代研究问题。
- 保留已有数据划分、种子、标签层级、实验协议和结论限定。医学/WSI 任务区分患者、切片、patch，不把切片标签当实例真值，不把算法指标写成临床获益；非医学题目不强加医学流程。
- 学术事实与参考文献在需要时查原始来源。不能获取来源时给待补材料清单，草稿可用“[待补：支持某主张的文献]”，不得造作者、年份、DOI 或看似真实的数字引用。
- 签名、成绩、审批意见不得生成；未知身份留空。封面和审核表等只按实际模板或用户要求加入。

## 交付前

按章节写法中的“成稿的读者检查”回看本次正文，核对关键判断的证据与限定、工作项覆盖、引用、数值口径和时间可行性。只修复当前问题，不强制输出检查表或无限润色。缺关键事实的全文称草稿，不把工作说明混入正文。

Word优先使用环境提供的documents工作流，否则用可用文档工具；本Skill不捆绑这些工具，也不要求安装其他学术Skill。保留可编辑内容与已有模板，生成后从最终文件渲染并逐页查看。分别说明文字完成、文件生成、解析、渲染查看和实际软件打开；缺工具或失败就披露未完成步骤，不将文本冒充Word。区分正式要求、范文观察和暂定格式，不反复追问已给信息。
