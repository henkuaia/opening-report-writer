# 开题报告格式指南

## 1. 适用范围与依据

本文件是可调整的制作建议，不是任何学校的正式模板或国家标准声明。不附带私人范文、原文件名、身份信息、审批记录或文档截图。精确排版必须读取用户当前提供的模板；没有模板时可采用下述暂定设置，并在交付时说明。

优先级为：用户明确要求及当前正式模板、指定参考的实际结构、暂定默认。要求之间冲突时说明差异，不将多份参考拼成未经确认的统一规定。不要依据范文推断用户学位、学校、学号、日期、字数或文献数量。

### 从参考材料学习

用户要求“学习这几份开题报告”时，分别识别可复用的章节职责、论证推进与版式设置，不只抄标题和字号。只学习时输出总结，不自动制作报告、修改原文件或更新Skill。

1. 确认材料是当前正式模板、填写说明、完成的范文，还是截图片段；记录实际能读取的范围。多个文件先看结构与差异，按用户要求覆盖，不凭文件名或一份范文概括全部材料。
2. 读取章节顺序和编号、正文与表格、节设置、样式及直接格式、题注、页码、引用和公式。结合渲染确认视觉效果；仅有纯文本不能判定字号与分页，仅有截图不能判定样式、域和公式可编辑性。
3. 对写法记录“该节回答的问题—段落怎样推进—用什么材料支持—如何衔接下一节”。区分范文的实际组织与建议采用的结构；论证不足的范文可作为待改进案例，不因它是参考文件就照搬。
4. 总结时给可回查的位置与适用范围，如模板的格式说明、具体章节、段落或渲染页。多份范文一致只能称观察到的共性；不一致就列差异，不能按多数票认定学校规定。精确数值未读到时标未知，不补猜。
5. 将学到的规则映射到用户题目：说明保留哪些章节职责、哪些内容应替换、哪些依赖新题目的证据。五部分骨架和本文件的暂定格式仅填补未指定处，不覆盖当前正式要求。

输出按需要使用简短对照表“观察/位置/适用范围/采用建议”，不强制另建台账。没有可读原文件时，只能给通用写法或阅读计划，不能称已经学完模板。

**虚构冲突示例。** 当前正式要求明确正文为12 pt、1.5倍行距，而两份旧范文均为10.5 pt、固定20 pt行距：采用当前要求；旧范文只作为其他未指定细节的参考。若仅取得纯文本，不能确认两份范文的实际排版，也不能声称已完成视觉核查。此例不是任何学校的标准。

## 2. 文档结构

正文默认五部分：选题依据、研究方案、预期目标、工作计划、主要参考文献，完整层级见[题目到方案](topic-to-plan.md)的“默认正文骨架”。当前模板不同则按模板调整，不额外创建创新点或可行性一级章。

封面、审核表、选题信息表、答辩记录、评议表和目录只在模板或用户要求时加入。审批表与选题表中的行列结构、纵向/横向合并单元格、复选框符号（`☑`/`□`）、固定填写说明及文末评议项目表必须完整继承实际模板或同校同级标准母版，不得凭主观印象简化为普通双列表格或擅自删减文末评议表。身份未知留空，不生成签名、成绩、评语或已发生答辩的记录。

不要根据 `TOC Heading` 样式名认定文档有目录；检查目录正文及 TOC 域。工作项数由题目决定，不能由模板示例固定。

## 3. 无模板时的暂定设置

以下仅用于需要 Word 且未提供格式要求的初稿，不覆盖已有文件格式。

| 对象 | 暂定设置 | 限制 |
| --- | --- | --- |
| 页面 | A4纵向，上下左页边距2.5 cm，右2.0 cm | 页眉页脚位置按实际内容调整；不称学校规定 |
| 正文 | 宋体，西文 Times New Roman，12 pt；1.25倍行距，两端对齐，首行缩进2字符 | 检查所需字体是否可用；不以 Normal 样式名推断实际字体 |
| 标题 | 黑体，一级15 pt，二三级14 pt；使用对应语义层级 | 沿用模板的加粗、段距和编号方式，不强加装饰 |
| 图表题 | 11 pt，图题在下、表题在上，无首行缩进 | 保持题注与对象相邻，必要时沿用模板字号 |
| 公式 | 可编辑数学对象，主体居中，编号靠右 | 用制表位或合适的无边框布局定位，不靠空格；检查编号变化 |
| 文献 | 顺序编码与文内引用对应 | 未提供标准时统一暂定体例，不冒称符合某版GB/T标准 |

保留黑色学术正文，正文不引入营销配色、装饰横线；流程图与机制图可采用协调的多彩分区配色区分功能模块，避免单调的纯黑白灰线框。不要通过压缩图内字号或裁切图片满足分页。

## 4. 编辑现有 Word

先检查纸张、节、页边距、样式、直接格式、网格、页码域及图表对象；纯文本不能表示全部格式，公式提取也可能漏掉符号。保留原稿，另存新版本，不仅提取段落后重建整份文档。

**母版容器原位复用（In-Place Template Grafting）：** 当用户提供了学校正式模板或同校同专业的标准范文 DOCX 时，必须以该 DOCX 文件作为底层容器复制出新文件，在原位替换正文内容（如定位`报告正文`至文末评议表之间的正文节点进行替换），**严禁新建空白 `Document()` 后从零手写简化的封面、审批表和选题表**。借用同校范文作为版式容器时，须彻底清空范文原有的姓名、学号、导师姓名、课题来源、指导教师意见、日期及旧正文，同时完整保留封面段落与下划线对齐、审批表/选题表/评议表的合并单元格与固定提示语、节属性（`sectPr`）、页眉页脚及样式表（`styles.xml`）；定稿交付时还须核对封面大标题下方是否遗留模板或旧稿的`（初稿）`字样并按实际交付状态清理。

语义标题与样式名称可能不一致。不要将长解释段误设为标题，也不要让目录收进整段正文。已有静态编号、自动编号或交叉引用优先沿用，避免两套编号叠加。

网格、`snapToGrid` 和行距共同决定视觉密度；1.25倍行距不能独立说明最终版式。字符缩进、twip长度与行相对段距不能混为同一单位。长字段用合理列宽和段落属性处理，不靠大量空格或空行撑版。

页码、首页不同、节起始页码以实际模板为准；不要把 PAGE 域缓存值写死为页码。新建文档的页码方案需明确，不能沿用不明来源的封面计数规则。

## 5. 图、表、公式与引用

- **尺寸与就近排版（图随文走）：** 按当前节的实际可用正文宽度设定图表尺寸；上述暂定页面的正文宽度为16.5 cm，不是所有文档的统一插图宽度，已有学校要求优先。图片保持纵横比并嵌入，不依赖本机外链。制作流程图或机制图时，按实际文档可用宽度设定画布或计算缩放至版心后的有效字号，避免超宽画布整体缩放到页面后导致文字过小；验收依据是最终嵌入文档后的清晰度、换行、重叠与裁切情况，不以源图字号或高分辨率自动判定通过。各子节的方法图、模块图紧随引出该图的正文段落就近插入（如`图2-2`插入`2.3.1`内、`图2-3`插入`2.3.2`内），不将多张模块图集中堆放在章节末尾。图内文字应为简明的模块、数据流与符号标注，不在图片内部塞入长段免责说明或规则提示。
- **流程图配色、工具选择与可编辑源码同步交付：** 流程图、技术路线图与模块机制图宜采用协调的多彩学术配色与线型（如按数据输入、冻结先验/教师分支、可训练主干/核心模块、损失约束、评估输出划分不同底色与边框色，并用实线/虚线区分训练与推理路径），避免单调的同色或纯灰白方框。按图型选用合适工具：总体技术路线图与流程框图可使用 Mermaid 代码（配合 `subgraph` 分区与 `classDef` 自定义色彩样式）或矢量绘图生成；包含张量维度变化、多分支特征交互或局部示意图的模块机制图，宜使用 SVG、Draw.io 或绘图脚本定制，确保纵横比与版心宽度匹配且缩放后文字清晰。生成并嵌入渲染图的同时，**同步保存并向用户输出对应的可编辑图表代码或源文件**（如 `.mmd` Mermaid 代码文件、`.svg`、`.drawio` 或绘图脚本），方便后续手动微调文字与布局。
- **防长英文/公式组合标识拉裂两端对齐行：** 分项标题、编号段落首句或表格文本若包含由加号、连字符或下划线连接的长串英文/符号组合（如 `MSE+Token+Teacher_Prompt`），在两端对齐（Justify）下极易因长词不可断行而将前一行汉字间距拉出异常空白；应在连接符两侧留出自然断行空格或改用紧凑中文名称配括号简写，并在渲染页面中复查字距。
- **按章编号与交叉引用：** 图表与公式编号按正文位置与既定规则一致；当图表采用按章编号（如图2-1、表2-1）时，公式编号亦须统一采用按章编号格式（如`（2-1）`而非`（1）`），具体遵循模板。修改后检查题注、正文引用、书签与交叉引用域。
- **表格版式：** 表宽不越界；按内容分配列宽，跨页按需重复表头，不用固定行高截断内容。审核表、实验表和无边框布局表用途不同，不强制全部改为三线表。
- **公式可编辑性与符号连续性：** 保留可编辑公式（OMML）及编号布局，逐式核对符号、上下标、缺字和换行，确保分步公式与总目标函数中的符号定义严格连续（不出现未定义的中间符号或同名异义）。公式截图不等于可编辑数学表达；公式字体根据模板及渲染支持确定。
- **参考文献对应：** 参考文献的条目、序号和正文引用须对应；题录真实性和支持关系另行核查。字体一致或引用格式整齐不证明文献真实。

### 参考文献与正文引文

**先选依据，再统一。** 当前正式要求及用户明确选择优先；其次采用指定范文中一致、清晰且无明显错误的做法；均未指定时才使用下列暂定体例。已有一致格式不因个人偏好重做。范文中的串条、跳号、文献身份混用不能照搬；作者姓氏大写、合理的 `et al.` 和静态编号本身不构成错误。没有核对正式规范，不宣称符合某版国家标准。

范文只有单篇引文时，只能据此观察单篇样式，不能推断多篇组合形式；截图不能证明具体字号、域结构或引用依据。未覆盖的组合形式可提出下表暂定做法并说明依据；若用户要求严格复刻却缺关键样例，询问缺失要求。需要采用通行规范时核实具体版本和适用要求，不凭记忆宣布某种形式一律正确。

**支持关系先于外观。** 按[正文主张与多篇引用](section-writing-guide.md#正文主张与多篇引用)区分共同支撑与分别支撑，再决定是否同组。把 `[1][2][3]` 上标不等于完成组合格式核查；合成 `[1-3]` 也不证明三篇均支持当前判断。只授权排版且材料不足时，完成可确定的格式处理，单列未核判断，不擅自改内容。

#### 按指定范文整理文末题录

1. **比较对象明确。** 读取待改报告与指定参照的文献章节，比较标题字体/编号间隔/段距，条目字体字号、对齐、编号间隔、悬挂缩进/制表位、行距/网格和跨页设置；再比较作者缩写、标点与各类来源的字段顺序。继承样式、直接格式和编号定义一起看，以页面效果核对，不用截图缩放估计精确数值。仅有截图时，只报告可观察差异；“一般排版可读”和“符合指定范文”分别判断。正式要求优先，范文的错误及不一致不照搬，也不称学校规定。
2. **局部适配，不换全文容器。** 已有报告只授权改文献时，在其副本上修改该节，不因另附范文就重建全文或复制其封面。保留文献集合、编号身份、正文引文上标、域/书签/链接及其他章节；文末编号保持基线，静态编号无需改自动编号。只改题录样式不授权全篇重编号。保留原稿，另存新版。
3. **分清显示与身份。** 可按所选体例统一姓名缩写间隔，但保留复姓、作者身份及顺序。具备完整刊名、年份、卷期及页码或文章号的期刊条目，仅在要求或授权允许时省略附加 DOI 展示；不是普遍删除 DOI 的规则，也不自动推广至会议、预印本等类型。依赖网络定位的条目保留必要标识、版本、日期与完整网址，不因范文未出现该类型就删字段、换类型或补造。来源身份或必要字段有疑点时定向核实，未决项放正文外。
4. **复现显示但不扩散修改。** 相同倍数行距可能因网格产生不同实际间距。只改该节时，不为匹配范文修改全文网格、页边距或公共样式；必要时用局部段落设置复现已观察的间距，并检查是否截字，说明实现差异。具体缩进、磅值来自本次参照，不把某次报告的数值写成通用默认。允许合理跨页，避免编号落单、仅剩一行的续页和人为大片空白；无需复制范文的不良分页。
5. **长标识与最终对照。** 两端对齐使网址前一行异常拉伸时，局部调整换行并复查实际词距，不能机械添加软换行后宣布完成；保留网址/DOI字符及链接目标，不用空格拆开标识，不缩小字体凑版。查看最终文件全部文献页及分页变化影响的后续页，覆盖一位/多位编号、长题名、网络来源；与参照比较视觉效果，同时核对来源与编号未变、其他章节及对象未误改。未受影响且已有有效检查的页面可复用。按用户需要展示实际修正版页面，不以范文截图或示意图冒充输出；分别报告参数检查、渲染查看、软件打开与题录事实核验。

**无要求时的暂定体例：**

| 对象 | 可采用的做法 |
| --- | --- |
| 正文引文 | 顺序编码，方括号整体上标，紧随所支持的词句；句末引文放在句号前，标点不随引文上标。Markdown或纯文本只表达编号，不冒称已设置Word上标 |
| 组合编号 | 同一引用组去重后升序排列，如 `[2,5]`；三个及以上连续编号可写为 `[2-4]`，混合为 `[2-4,7]`。范围压缩不得增删来源；不同分句的来源不要为凑成一组而合并 |
| 文末编号 | `[1]` 起按正文首次出现顺序排列；同一来源复引沿用同号。编号不上标，与题录间留清晰间隔，续行对齐题录文字而非编号 |
| 作者 | 保留实际作者顺序；未指定时可列前三位，超过三位用“等”或 `et al.`，英文采用姓在前、名缩写。大小写、缩写间隔统一，不因统一风格破坏复姓、团体作者或名称身份 |
| 字体与段落 | 新建且无模板时可沿用第3节的宋体/Times New Roman、12 pt、1.25倍行距；题录暂用左对齐，避免长网址拉大词距，取消首行缩进并采用悬挂缩进。宽度按最长编号及间隔设置，约1 cm可作起点，不固定为学校要求 |

**题录按来源身份组织，不用一个模板套所有条目。** 以下是字段骨架，不是真实题录；`<…>`表示需依据来源填写的字段，不能把占位符当成正式完成项。类型标识及字段顺序服从当前指定体例；无要求时可暂用下列写法。原来源没有卷期、页码或DOI时，不为填满骨架而编造。

- 期刊：`[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 页码或文章号. DOI: <已核实DOI>.`
- 会议：`[序号] 作者. 题名[C]//论文集或会议名称. <适用且已核实的出版信息>, 年: 页码或文章号.` 保留工作坊等真实身份，不从会议缩写推断主会收录；出版者、卷号等有依据且适用时保留。
- 预印本：`[序号] 作者. 题名[EB/OL]. <平台与标识、所引版本>, <该版本年份>[<实际访问日期>]. <网址>.` 不将首次提交年、修订版年和正式出版年混用。
- 网页：`[序号] 责任者. 页面准确题名[EB/OL]. <已知发布日期或更新日期>[<实际访问日期>]. <网址>.` 日期未知不补造；只在实际访问后记录本次日期，不倒填历史访问日期。
- 公开软件、数据及其他来源：仅在用户允许的收录范围内，按已核实的责任者、名称、资料类型、版本或日期及定位信息组织。区分集合网页与实际使用的数据集版本、论文与实现仓库。内部代码、工作文档和记录不适用此题录骨架，先按[章节写法的题录准入规则](section-writing-guide.md#题录准入与项目证据安置)处理；用户仅收录论文时，不把网站或软件包装成论文。

优先复用已核实且未变化的来源，只对缺失、矛盾和本次涉及字段定向回查出版商、正式论文集、原文或官方记录。DOI或预印本标识中的数字不能单独决定出版年。正式版存在不意味着可自动替换实际阅读版本；必要版本信息应保留，不能把不同版本的作者、年份、页码和结论拼成一条。仅要求格式整理时，不擅自扩大为全篇文献重检；发现会改变来源身份的疑点，保留并单列待核项。

正式题录保留检索与身份所需信息，移出“已核查”“不要混用版本”等助手工作说明。内部材料不因移出本机路径就获得题录准入资格；相关正文是否保留及来源如何安置，遵循章节写法的正文边界与题录准入规则，不能把用户排除的内容改成表下注释继续保留。未解决字段和核查说明放正文外，不用工作提醒代替题录。

**每次引文编辑均需保护，包括仅修上标或组合格式：**

1. 在授权的正文、表格、题注和图下注释中结合上下文与来源表识别引文，不把向量、区间或公式号当成引文，不能只靠数字正则匹配。
2. 同组规范化前后展开编号并比较来源集合，如 `[1][2][3]` 与 `[1-3]` 等价，而 `[1,3,5]` 不能压成 `[1-5]`。只有已确认属于同一支持范围的相邻引文才合并；局部格式调整不改变全文编号身份。
3. 保留有效引用域、书签、超链接、公式及非引文格式，不将整段转成纯文本重建。复杂域无法安全合并时先保留结构，说明组合格式未完成，不能为外观破坏交叉引用。上标仅覆盖方括号、数字与组内分隔符，相邻正文和标点不随之上标；字号、字体及间距按已确认依据处理，不任意缩小字号模拟上标。

**全文重编号仅在授权覆盖相关正文与文献表时执行，在上述保护步骤之外：**

1. 确认编辑基础及引用制度。采用作者—年份制或另有正式规则时，不改成上述顺序编码；只修一节时沿用章节写法第5节的局部引用规则。
2. 先展开组合及区间，建立“旧号—来源身份—新号”映射，再一次性更新引用及文献表，避免连续字符串替换串号。论文与代码、不同版本可能是不同来源；删除或合并前检查全部引用用途，不能为编号漂亮而丢证据。静态编号不必一律改成域。
3. 复查首次出现顺序、复引一致性、文内文末双向对应、悬空引用、未引条目、重复身份及一号多源。附记引文组数与展开来源次数时分别统计，不能把数量变化直接当成增删文献。

**Word检查重点。** 检查一位与多位编号的间隔、续行和悬挂缩进。长网址优先自然换行，必要时作与题录相连的续行，保留完整字符及已有链接目标；不要插入会改变网址的空格或连字符，也不缩小字号或改页边距来塞内容。检查引用密集页、全部参考文献页及分页变化影响的后续页，避免编号与题录分离、网址孤立或越界。对照修改前后非引用数字、图表号和可编辑公式；若导出PDF，从最终DOCX直接导出，并区分解析一致、实际渲染查看与软件打开，不把字符串检查称为视觉通过。

验收分开判断：引用与主张是否匹配、规范化前后来源集合及编号身份是否一致、最终Word上标与组合形式是否符合采用依据。核对上标仅作用于引文，标点保持基线，字体字号及域/书签/链接未误改；实际查看最终文件的单篇、多篇、句末及本次涉及的表格/题注引文。只完成其中一项不代表其他项通过，缺少的原文或工具仅影响相应结论。

含引用域时，不能只检查缓存结果的上标属性：在修正版上测试相关域更新后再渲染，确认编号与格式仍成立。若更新后格式回退，在保留域类型、目标及有效开关的前提下修复格式保持设置，并复测；不靠解除域、锁定域或把文末编号也设为上标规避问题。无法实测时将“域更新后保持格式”列为未验证。

## 6. 验证与交付

文件生成后检查结构完整性、图片关系、公式和引用；从最终 DOCX 导出或渲染，并逐页查看图表溢出、题注落单、孤立标题、异常空白页、页码与公式缺字。修改造成后续分页变化时，检查范围覆盖受影响页面。

按实际插入尺寸查看图内文字与线条；单独图片放大后清晰不能代替最终页面检查。不得用截图正文替代可编辑内容，也不将重排的独立 PDF 冒充最终 Word 导出。

区分文件已生成、可解析、已渲染查看和在 Microsoft Word 中实际打开。缺少工具时披露实际完成范围；只修复发现的问题，不无限扩大检查。交付文件及必要限制，不附带用户原始参考材料。
