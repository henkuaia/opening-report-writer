# 虚构开题报告节选

## 1.1 选题意义

本课题关注电池供电温度节点在有限采样资源下保留温度变化信息的问题，不研究无线传输协议优化。

## 1.2 研究现状

温度采样策略的一个比较维度是：下一次观测的时刻是否随已观测到的变化调整。甲采用10秒固定间隔，在慢变序列上评价采样次数和重构误差，采样时刻不因最近的温度样本改变[材料甲，第1段]。乙依据最近两次已取得样本的差异调整下一次间隔，将采样安排与已观测变化联系起来；其评价同样限于慢变序列的采样次数和重构误差[材料乙，第1段]。两者因而不仅是算法名称不同，而是在采样决策所利用的信息及更新时间安排上存在差异。

这种反馈机制依据的是已经取得的样本，而不是采样间隔内持续可见的真实温度[材料乙，第1段]。因此，对本课题要求的突变检出而言，需要进一步考察变化尚未被观测时，下一次采样的等待会怎样影响检出时延。现有两段材料没有提供突变检测或整机能耗评价，不能据此判断策略是否满足本课题的5秒要求，也不能从采样次数推断整机节能[材料甲，第1段；材料乙，第1段]。本课题据此关注采样数量与突变检出约束之间的取舍；这是面向本题条件的待验证问题，而非已经确认的领域空白。

## 2.1 研究目标

本研究拟在减少采样次数的同时，使突变发生至首次检出的时延不超过5秒。固定10秒采样保留为原始对照。已有慢变序列，尚无突变序列或整机能耗实测，不研究无线传输协议优化。

## 2.3 研究方案

拟以已有慢变序列考察重构误差与采样数量，并补充具有明确事件起点的突变测试序列，用于检验采样策略在变化出现后的响应。突变的幅度、持续时间、检出判据及参考序列时间分辨率需按监测需求明确，当前不预设取值。测试时各策略接收同一参考输入，但只在各自决定的采样时刻取得温度值；完整参考序列和事件起点仅用于评价，不向采样决策提供尚未观测的变化。

自适应策略拟依据最近两次已取得样本的差异决定下一次间隔，具体调整规则尚未确定。由于这一决策不能预知两次采样之间新出现的突变，拟考察限制最大采样间隔能否避免过长等待，并把采样后处理所需时间计入检出时延。间隔上限需在上述时间开销和5秒要求下确定，不直接把5秒采样间隔等同于5秒检出保证。强化学习不作为已确定的方法，先明确可解释的间隔调整规则及其验证问题。

固定10秒采样保留为原始对照，用于观察采样安排改变后的误差与数量变化；若事件发生在采样间隔内，仅等待下次采样就可能超过5秒，因此优于这一对照不等于满足检出要求。拟增设固定5秒采样作为候选对照，统一重构方法、事件检出规则和测试输入，比较它与自适应策略在约束下的表现。该候选对照也须实测检出时延，不能预先视为合格策略。

验证拟记录每个测试事件从参考起点到首次检出的时延，并单独保留未检出的事件，不能从时延统计中删去漏检来形成达标结论。在给定测试范围内，有事件超过5秒或未检出，就不能宣称实现了该范围内的检出目标。采样数量变化与检出是否达标分别报告；只有相对明确对照减少采样且满足检出约束，才支持两项目标同时实现。重构误差使用同一参考序列和统计方式比较，在尚无容限要求时报告误差与采样数量的取舍，不自行判定误差已经达标。已有慢变序列不能替代突变测试，未取得相应材料前保留这一验证缺口。

整机能耗拟在具备测量条件后，以相同设备、输入和观测窗口单独测量，其他设置保持一致，不增加无线传输优化内容。采样次数下降仅说明采样活动减少，是否节能仍取决于整机测量；若检出时延超限或能耗上升，应分别报告未满足的目标与已观察到的变化，不用采样数量改善抵消失败。当前尚无整机能耗实测，不能据此预告续航提高。
